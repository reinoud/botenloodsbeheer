# Terugblik aegis, 2026-11-04

Taak: securityreview van de gestagede diff voor issue #91 (413-handler leest het lichaam weg).

## Wat ging goed

De brief noemde de toetspunten (begrenzing, geheugen, tijd per worker, chunked, omweg om Traefik). Daardoor bleef de review klein: één diff van vier regels, plus de labels in `docker-compose.yml` en `compose.api-extern.yml` en de CMD in `docker/Dockerfile`.

## Wat kon beter

De brief noemde alleen `docker-compose.yml` voor de grens van 3 MB. De tweede router (`api-extern` in `compose.api-extern.yml`) moest ik zelf zoeken. Die heeft de middleware `3mb` ook.

## Wat deed je zelf goed

Ik heb beide routers naar de API gecontroleerd op de middleware `3mb`, en de directe route naar `api:8000` (netwerken achterkant en voorkant) apart beoordeeld. Een losse proef op Gunicorn was niet nodig, want de aannames volgen uit de configuratie.

## Wat heb je onderweg verbeterd

Ik heb het punt over chunked encoding niet als bevinding gemeld, maar eerst nagegaan of het een nieuw risico is. Dat is het niet: een sync-worker kan via de directe route ook zonder deze wijziging tot de timeout van Gunicorn (30 seconden) bezet worden gehouden.

## Wat kan structureel beter

Zet in de opdracht: noem bij een review op de grens van de API elke router naar de dienst `api`, dus ook die uit `compose.api-extern.yml`.
