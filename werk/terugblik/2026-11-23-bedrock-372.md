# Terugblik bedrock, issue #372 (404 van Traefik)
Datum: 2026-11-23

## Wat ging goed
Het onderscheid is met een live aanroep bewezen vóór de bouw: Traefik geeft platte tekst "404 page not found", de API JSON `{"fout":"Onbekend pad."}`. Vier mutanten, elk op een eigen test gevangen.

## Wat kon beter
De brief noemde `tests/integratie/`, maar de koppelingstests staan in `tests/unit/test_integratie.py`. "Hooguit vijf keer" kan vijf pogingen of vijf herhalingen zijn; ik koos vijf herhalingen na de eerste 404. Ik werd afgebroken door een API-fout (529) en moest de rest in een tweede ronde doen.

## Wat deed ik zelf goed
Eerst de API-code doorzocht en de proef op de draaiende stack gedaan; ADR-012 en ADR-013 meegenomen, die het uur nog noemden.

## Wat heb ik onderweg zelf verbeterd
Mijn eigen telling-test liep door een geplande import heen; `geslaagd_op` voorgezet. Volledige suite eerst fout gedraaid (verkeerd compose-project, geen database); opnieuw met `-p botenloods` en een eigen `TEST_DB`.

## Wat kan structureel beter
Zet in de opdracht: "Een worktree heeft een eigen compose-projectnaam en geen `.env`; geef `-p botenloods --env-file <hoofdmap>/.env` mee voor de unitsuite, plus een eigen `TEST_DB`-conftest." Zet ook: "Noem bij 'hooguit N keer' of het N pogingen of N herhalingen zijn."
