# botenloodsbeheer

Webapplicatie voor het beheer van de botenloods van een kanovereniging.

- Projectregels staan in `docs/PROJECT-OVERLAY.md`. Lees die eerst.
- Leidende bron voor scope en besluiten: `docs/business/intake.md`.
- Governance komt uit `/Users/reinoud/Projects/AI/Prompt Pack/`. Verwijs ernaar, kopieer niets.
- Hosting met een eigen docker-compose, niet op Hansel (besluit stakeholder 2026-10-30). De 12-factor-basis blijft gelden.
- Open werk staat in GitHub-issues van `reinoud/botenloodsbeheer`.
- Elke feature in een eigen branch, naar `main` via een pull request dat de sessie na review zelf mergt (overlay §4, besluit stakeholder 2026-11-05).
- Teksten volgen de skill `schrijfstijl`. Code schrijven en reviewen gebeurt met de skill `ponytail`.
- Agents schrijven hun terugblik in `werk/terugblik/`.
